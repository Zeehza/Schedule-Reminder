# Privacy Policy (Kebijakan Privasi)

**Berlaku mulai:** 21 Agustus 2026

Kebijakan Privasi ini menjelaskan bagaimana **Schedule Reminder Bot** mengumpulkan, menggunakan, dan melindungi informasi Anda.

## 1. Data Apa Saja yang Kami Kumpulkan?
Bot ini dirancang untuk mengumpulkan data seminimal mungkin yang diperlukan agar fitur pengingat dapat berfungsi:
* **Data Server (Guild):** ID Server Discord, ID Channel (untuk mengirim pengingat), dan ID Role (untuk keperluan mention).
* **Data Pengguna:** ID Discord pembuat tugas (opsional, untuk pencatatan siapa yang membuat tugas).
* **Konten Tugas:** Deskripsi tugas, tenggat waktu (deadline), dan tautan/link yang Anda ketikkan atau berikan ke dalam bot.

## 2. Bagaimana Kami Menggunakan Data Anda?
Data yang dikumpulkan **hanya** digunakan untuk operasional fitur inti bot, yaitu:
* Menyimpan jadwal tugas Anda.
* Mengirimkan notifikasi dan pengingat ke channel/server yang tepat pada waktu yang ditentukan.
* Menampilkan daftar dan riwayat tugas saat diminta melalui command Discord.

## 3. Perlindungan & Pembagian Data
3.1. Kami tidak pernah menjual, menyewakan, atau membagikan data Anda kepada pihak ketiga mana pun.
3.2. Data disimpan dengan aman di dalam database yang dilindungi oleh kredensial akses.
3.3. Bot ini **tidak** membaca isi chat Anda di server. Bot hanya membaca pesan yang diawali dengan slash commands (contoh: `/new`, `/list`).

## 4. Penghapusan Data
4.1. Anda dapat menghapus data jadwal spesifik menggunakan perintah `/remove`.
4.2. Admin server dapat mengatur ulang channel dan role kapan saja.
4.3. Jika Anda ingin semua data terkait server Anda dihapus secara permanen dari database kami, Anda dapat menghubungi pengembang atau membuat laporan *issue* di GitHub.

## 5. Hubungi Kami
Jika Anda memiliki kekhawatiran tentang privasi Anda atau memiliki pertanyaan terkait cara bot ini menangani data, silakan hubungi pengembang proyek ini melalui GitHub.
